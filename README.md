**Solmar Heat** — a complete open-world crime game set in the sun-soaked coastal city of Solmar Bay. You are Jax Marlowe, a wheelman in debt to the Breakers. Steal cars off the street, outrun the Bay PD through a living city of traffic and pedestrians, and work through five chained story missions — from borrowing Dee's first set of wheels to robbing the Solmar Bank — with fists, a pistol, a wanted level that runs from one to five stars, a live minimap, day lighting, and save/load so the story waits for you.

## Run it
```sh
node serve.ts
```
then open http://localhost:8080

## How to play
- **WASD / arrows** — move on foot, drive in a car
- **E** — enter / exit a car, talk, advance dialogue
- **F or mouse click** — punch, or shoot with the pistol
- **Space** — handbrake
- **M** — mission list · **Esc** — pause · progress saves after each mission
- On-screen touch buttons appear on mobile.
