Solara Bay — an open-world crime game. Drive and steal cars across a sun-soaked coastal city, outrun the Solara Bay PD through a 5-star wanted system, fight the Tide Kings, and run five story missions for fixer Mara Voss — with traffic, pedestrians, a live minimap, a save, and synthesised sound.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD/arrows to move or drive, E to enter cars and talk, F or click to fight, Space for the handbrake, M for missions, P to pause.
